## Temuan yang perlu diketahui

- **Rollback create-table bisa menghasilkan data keliru tanpa error.** Setelah rollback + migrate ulang `gamification_levels`, `GET /gamification/me` dan dashboard student tetap HTTP 200 tetapi `gamification_level` menjadi 0 (seharusnya 4). Ini dasar keputusan 2.
- **`GET /up` tetap 200 saat `php artisan down`**; API 503. `/up` bukan penanda maintenance selesai.
- **Pasca-restore:** token yang password-nya berubah setelah backup → 401; token terbit sebelum backup tetap valid; aktivitas setelah backup hilang; `cache:clear` wajib. Terbukti di E2.
- **Lingkungan test:** `.env` berbasis `.env.example` (`APP_URL=https://…`) membuat 2 test `EnforceHttpsTest` gagal; dengan `APP_URL=http://localhost` suite 518 passed / 2814 assertions (cocok baseline). Bukan bug kode; dicatat di runbook bagian 9.
- **HEAD zip `afa658c`** berbeda dari yang disebut pesan tugas (`85d8b27`, 515 passed); baseline §18 untuk `afa658c` = 518/2814.
- `php artisan test` memakai `RefreshDatabase` dan menghapus isi database yang dipakai: selalu gunakan database terpisah.
