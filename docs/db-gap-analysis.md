## Catatan Boundary

- Tabel `habits`, `indicator`, `student_habits`, `student_habit_backups` terkait (di luar `student_habit_backups` yang di-DROP) **tidak diubah** di task ini — milik HABIT-001/STUDENTHABIT-001.
- Service/Controller/Request/Resource yang masih membaca kolom lama (`level`, `is_active`, `classroom` di Teacher/Student, `QrUser`, tabel `headmaster` singular) **tidak diubah** di task ini — masing-masing milik AUTH-001, SCHOOL-001, HEADMASTER-001, TEACHER-001, STUDENT-001. File-file itu akan error terhadap skema baru sampai task REWORK masing-masing dikerjakan; ini sudah diketahui dan dicatat di Dependency Task Board.
